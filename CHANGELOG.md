## [0.1.0] - 2026-08-24

- Initial release.
- Queue-first IndexNow submission with explicit after-commit dispatch.
- Exact-host grouping, protocol-safe batching, and scoped key locations.
- Per-URL cache debounce compatible with database, Redis, and array stores.
- Correct handling for accepted, permanent, rate-limited, and transient responses.
- Host-safe key route, diagnostics, manual submission, and sitemap backfill commands.
- Opt-in Eloquent lifecycle integration.
